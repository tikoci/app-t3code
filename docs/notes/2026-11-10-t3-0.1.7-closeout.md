## The base that is in place

- **Image vs home.** The image carries T3, Node, Bun, `uv`, `gh` and the
  core tools. Provider CLIs (`T3CODE_PROVIDERS`) and tool groups
  (`T3CODE_TOOL_GROUPS`) install into `/data` at runtime, as `node`, with
  verified payloads. Background logs go to `/data/.local/state/t3code/`.
  `t3code-tools status` and `t3code-providers status` report both.
- **CI.** `lint-test` → `build` (amd64 replacement test, multi-arch push)
  → `arm64` (native) → `promote`, which runs only on `main`. Docs-only
  changes skip the build.
- **Repo.** The `main` ruleset (a PR with resolved threads; `lint-test`
  and `build`), CodeQL, secret scanning with push protection, Dependabot
  (security PRs, plus monthly GitHub Actions updates), and daily freshness
  checks with a drift issue.
- **Docs.** `SECURITY.md`, the CHANGELOG `-app.<N>` scheme, and
  `AGENTS.md` for the workflow.
